---
name: initialize
description: Initializes the browser for debugging and verifying userstyles.
---

- Open a browser via the chrome-devtools MCP.
- Install the Stylus extension from the stylus directory
- At a time, we debug one userstyle. User will provide its name.
- Find out the userstyle's absolute path. It will be located in the sites directory.
- Open that file in a browser tab. The Stylus extension will automatically detect the userstyle and load its installation page.
- Click Install style
- Check Live reload checkbox
- Keep the style tab open.
- Open a new tab and wait for further instructions from the user.
